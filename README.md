# Advanced AI – Drug Safety Detector

## 📌 Overview
Drug Safety Detector is an AI-powered application designed to analyze medical or drug-related text and identify potential safety risks, adverse reactions, or critical alerts.

This project combines a frontend interface with a backend AI processing system to provide intelligent drug safety insights.

---

## 🚀 Features
- AI-based drug safety analysis
- Backend API integration
- Frontend user interface
- Real-time prediction results
- Clean and structured architecture

---

## ⚙️ Tech Stack
- Python (Backend)
- FastAPI / Flask (API)
- React (Frontend)
- Machine Learning / NLP

---

## ▶️ How to Run

### Backend
```
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```
cd frontend
npm install
npm start
```
